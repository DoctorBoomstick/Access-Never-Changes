# Changelog

## 1.0.2 (2026-11-06)

The mod now supports subtitle reading. Subtitles in cutscenes are read in sink with spoken dialog as lines come up, and are saved to the mod’s log for later perusal. Thanks to zargonbr on audiogames.net for the suggestion.

## The mod's own keys can now be rebound via keys.ini, a shortcut to which has been included in the Start menu. The F1 help reflects what you’ve set your keybinds to, and should you include a key value that the mod does not recognise, it will default to... well, defaults. There was probably a less idiosyncratic way to write that.

## 1.0.1 (2026-10-24)

Previously, the mod read the game's text as though every language were English. Fallout 2 writes each translation in its own character set, with the result that languages like Russian came out as gibberish, Polish, Czech and Hungarian lost their accented letters, and accented names in other languages went missing from the character sheet and Pip-Boy. Each language is now read in its own character set. Thanks to morozx1 on audiogames.net for reporting.

When choosing somewhere on the world map to travel to, the mod would ever so politely inform you that the game hadn't taken it, even when it had. This has been fixed, and the mod no longer lies.

Travelling on the world map now plays a sound for every tile crossed, as walking does on the explore view. The cursor no longer makes a noise as you move it around the world map.
